# Midnight Skinning Companion

A World of Warcraft: Midnight addon for the Skinning profession for
tracking Renowned Beast kills, also simplifies crafting the associated
skinning lures, and helps you get in position to use them. Only
active on characters who have learned Skinning.

## Features

- **Tracks Renowned Beast kills** so you can check if you've done them today.
- **Lure crafting helper** - shows reagent status and lets you craft
  a lure directly from the addon window.
- **Lure overlay** - an on-screen indicator when it's time to use a
  lure, with Edit Mode support to reposition and scale it.
- **Waypoint integration** to help you get to the right spot.
- **Auction House helper** for sourcing lure reagents.
- Minimap button and addon compartment entry, both optional.
- Localized into all client locales WoW supports.

## Localization caveat

Locale strings were written through AI and may sound unnatural or
even be plain wrong; feel free to open an Issue or Pull Request
fixing your locale.

## Slash commands

- `/msc` - open the addon window.

## Installing

Grab a release from CurseForge or the GitHub Releases page and
extract it into your `Interface/AddOns` folder like any other addon.
